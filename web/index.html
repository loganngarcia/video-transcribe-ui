    Your reader

    The page starts a sandboxed Python runtime in your browser automatically. USR 2.0 still needs a compatible PyTorch reader until its native dependencies are available for WASIX.

    The same USR 2.0 model in every mode. Speed depends on your reader's hardware.

    Advanced: run the native USR 2.0 reader

    The browser runtime is automatic. For actual USR 2.0 inference today, the proven native reader still uses Python, PyTorch and FFmpeg:

    python scripts/setup_model.py
python scripts/run.py

    GitHub Pages hosts the interface and Wasmer runtime. The current upstream USR 2.0 PyTorch/OpenCV/MediaPipe stack is not yet WASIX-browser compatible, so the model itself still runs on the reader.

    A few things to know

    Camera Transcribe reads visible speech in English using USR 2.0. It never requests microphone access.

    Record or upload a short clip, preview it, then choose Transcribe. Only then is that clip sent to the reader address you selected. Uploaded files may contain audio; the server discards that track before inference.

    Video is deleted after processing. Results expire on the server after five minutes and are cleared sooner when retrieved by this interface. Your tab keeps editable session history until you refresh or clear it. Settings are saved locally; connection keys are not.

    This is experimental lip reading. Similar-looking sounds can produce incorrect words, and intentionally silent mouthing may be harder than normal speech. No language model rewrites your transcript.

    Read aloud uses your browser's speech service; voice processing depends on your browser and operating system.
