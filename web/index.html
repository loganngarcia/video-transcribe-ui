    Transcription options

    The default mode runs locally on this device. The speech model starts downloading as soon as the page opens and is cached by the browser when possible.

    Used only with a connected native reader.

    Advanced: use the native USR 2.0 Huge reader

    The default browser path already runs actual USR 2.0 Base+ locally. For the larger Huge model and ESPnet beam decoding, run the optional native Python/PyTorch reader:

    python scripts/setup_model.py
python scripts/run.py

    Then choose Connected USR 2.0 server above. The local browser reader remains available without any server.

    How it works

    Video Transcribe reads visible speech in English using USR 2.0. It never requests microphone access.

    Record a short clip or choose a video file. Stopping a recording or choosing a file starts transcription automatically—there is no separate Transcribe step. With the default This device reader, face tracking, mouth cropping and USR inference all happen locally and the clip is not uploaded. If you explicitly choose a connected server, that server receives the clip and strips any audio before inference.

    Local transcripts stay in this tab until you refresh or clear them. Connected-server video is removed after processing and server results expire after five minutes. Settings are saved locally; connection keys are not.

    This is experimental lip reading. Similar-looking sounds can produce incorrect words, and intentionally silent mouthing may be harder than normal speech. No language model rewrites your transcript.

    Read aloud uses your browser's speech service; voice processing depends on your browser and operating system.
